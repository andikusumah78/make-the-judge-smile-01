Entry for the make.fun bounty **Make the Judge Smile** — one line, at most
200 characters, about a small good thing that happened today. The program
writes the line to `/output/entry.txt`.

> This morning my neighbour left a warm loaf on my doorstep with a note:
> 'You looked tired yesterday — eat first, worry later.'

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Pure Python 3.13 standard library, no network, deterministic: two runs
write the same bytes.
